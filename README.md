# AIMeter

macOSのメニューバーとウィジェットに、AIツールの利用量を表示するSwiftUIアプリです。
Codex、Gemini / Antigravity、Claude Code、Grok Bot、GitHub Copilot、Windsurf、Cursorのローカルデータを集計します。
各AIサービスとは独立した非公式ツールです。表示値にはログからの推定や設定した上限が含まれ、公式の請求額・残量と一致するとは限りません。

## 公開内容と環境

このリポジトリはMIT Licenseでソースコードを公開しています。署名・公証済みのアプリはまだ配布していません。GitHubの「Source code」ZIPはアプリ本体ではないため、利用するにはソースコードからビルドしてください。

- 実行対象：macOS 14以降
- ビルド：macOS 27 SDKを含むXcode（新しいSwiftUI APIを参照）
- Swift Package Manager。外部Swiftパッケージへの依存なし
- アプリバンドルの生成とPythonテスト：Python 3.9以降
- 通常のアプリ動作にPythonは不要

Apple Siliconの合成データによるテストと、実際の配布候補の動作確認は別です。新規macOSユーザーでの初回起動・設定・Widget実表示、Intel実機・macOS 14、任意APIの実接続については、各確認結果を個別に扱います。ソースの公開は、これらの確認や配布アプリの公開を意味しません。

## ビルドとテスト

先に実行中のビルド、メモリ、出力先の空き容量を確認してください。

```sh
git clone https://github.com/TaigaShinohara/AIMeter-public.git
cd AIMeter-public
swift build -c release -j 2
swift test -j 2
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s Tests -p 'test_*.py' -v
```

テストは一時ディレクトリの合成データを使い、個人の利用ログやAPI資格情報を必要としません。実Antigravityへの接続テストは通常実行ではスキップします。

アプリバンドルを生成するには、次を実行します。

```sh
./scripts/build_app.sh
```

毎回新しい `.build/local-packages` 配下へローカル用アプリとZIPを生成し、設置・起動・Widget登録は行いません。署名IDがない場合はad-hoc署名を使います。ローカル用ZIPは、署名・公証済みの配布物ではありません。

`./run.sh`、`make run`、`Launch AIMeter.command` は必要に応じてビルドし、アプリを設置・起動します。設置を避ける場合は `AIMETER_INSTALL_TO_APPLICATIONS=0 ./run.sh` を使います。起動したアプリは通常のログ収集を行うため、テスト実行とは区別してください。

詳しくは [配布・導入ガイド](DISTRIBUTION_GUIDE.md)、開発に参加する場合は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## 主な表示

- 本体・メニューバー・浮遊ウィンドウで、残量の要点と全期間の表示を切り替えられます。公式値、設定上限からの目安、未取得を区別します。
- LiquidBall（リボ）が、残量とデータの鮮度に応じて短い案内を表示します。詳しくは [上部のひとこと案内](docs/CHARACTER_SUMMARY.md) を参照してください。
- macOSのWidgetは小・中・大に対応し、本体が保存した表示情報を使います。独自のログ収集やAPI通信は行いません。
- 任意のAntigravity連携は、起動・ログイン済みのデスクトップアプリが返すモデル群別の公式残量を表示します。Geminiのログ由来の推定使用量とは別です。[Antigravity連携](docs/ANTIGRAVITY_QUOTA.md) に取得条件と制限があります。

## アプリのアップデート

設定 → 一般 → アプリのアップデートから、この公開リポジトリのGitHub Releasesを確認します。現在は配布Releaseがないため、インストールできる更新はありません。この公開先の確認やソースの取得にGitHub CLIのログインは不要です。

将来の安定版には「最新版に更新」、prereleaseには「開発用 → 開発版に更新」を使います。ソースのmainを取得してビルドする機能ではありません。自動確認・自動インストールは行いません。

配布物が提供された場合は、ZIPのSHA-256、固定のDeveloper ID署名元、Apple公証を検証してから更新します。以前のアプリは設置先と同じフォルダ内に退避して保持します。書込み権限のある場所から実行してください。公式の署名元と異なる独自配布は、この更新機能の受入対象にはなりません。

リリース担当者向けのビルド・署名・公証・公開手順は [docs/RELEASING.md](docs/RELEASING.md) にあります。

## データと通信

保存項目、表示と取得停止の違い、キーの保守操作は [プライバシーの説明](docs/PRIVACY.md) にまとめています。

- ローカル収集は各ツールの既定パス、または設定画面で指定したパスを読み取ります。アプリ本体はApp Sandboxによるホーム配下への制限を持ちません。
- 集計結果は `~/.ai_meter_usage.json` に保存し、所有者だけが読み書きできる権限（0600）を設定します。集計・Widget表示cache・DBコピーの新規ファイルは、作成時からACLの継承を拒否し、本文を書き込む前に所有者・0600・追加ACLなしを確認します。権限を確認できない保存先では書込みを拒否し、既存の集計を保持します。ログ本文をこの集計ファイルへ保存する設計ではありません。
- macOSのWidgetは、本体が `~/.ai_meter_widget.json`（0600）へ保存した表示情報を読みます。共有schema 4では未使用の費用を保存せず、数値表示がオフなら使用量・上限・それらの表示文字列も保存しません。割合・更新時刻・期限等は残します。本体の集計は別に保持します。APIキーやログ本文は含めず、Widget独自のログ収集・API通信は行いません。共有ファイルの更新を確認できない切替は未適用として案内します。
- Widget用の表示情報が未取得・欠損・不正な場合は起動・更新を案内し、全サービスが無効の場合は設定を案内します。サンプル値はギャラリープレビューに限って使用します。OS側の都合によりWidgetへの反映には時間がかかる場合があります。
- 任意のOpenAI連携を有効にし、保存済みのAdmin Keyがある場合は、OpenAIの組織利用量・費用API（`api.openai.com`）へ認証付きで通信します。Admin KeyはmacOS Keychainに保存します。編集内容は下書きとして扱い、保存と一致する値の読戻しを確認したキーだけを連携に使用します。書込み自体に失敗した場合は以前の値を保ちます。書込み後の確認に失敗した場合は未完了とし、新しい値を通信へ使いません。移行元の旧設定は移行を確認できるまで保持します。
- 任意のGCP連携を有効にし、GCP Project IDを設定した場合は、ローカルの `gcloud` と既存のログイン情報で取得するトークンを使い、Google Cloud Monitoring（`monitoring.googleapis.com`）へ通信します。GCP Project IDはアプリ設定に保存します。`gcloud` は既定の候補パスから、symlinkの途中を含む祖先・所有者・権限・ACLを確認できる実行ファイルのみを使用します。SDKとその依存物は利用者が信頼して導入したローカルソフトウェアであることが前提です。子プロセスの出力・実行時間・終了処理には上限があります。
- サービスを無効にすると、そのサービスのローカルログ収集と任意クラウド取得を停止します。メニューバー表示の切替は表示だけを制御します。無効な間は通常の更新でキーを読み込まず、gcloudやAPI要求を開始しません。収集中の無効化は保存権限も取り消し、遅れて戻る旧結果を反映しません。OpenAIのKeychain保存値は残ります。連携がオフでも、本人が選ぶ保守操作で旧平文設定の移行や保存済みキーの削除ができます。移行保存と読戻しが確認できない場合は旧設定を保全し、未完了と案内します。
- 利用量の推定には会話本文を端末内で一時的に読み、トークン情報がない場合に文字数を使うことがあります。本文そのものを集計・Widget・ログ・API要求へ渡しません。WindsurfはDBとWALの私有コピーから必要なプラン項目を取得します。コピーは専用の保護領域とOSロックで管理し、次の起動でも識別できる自作残留だけを回収します。元のAIログや他アプリのファイルは清掃しません。
- 旧手動スクリプト `scripts/update_usage.py` は通常のアプリには同梱しません。既定ログは固定の状態だけで、保存は既知項目へ限定し、ファイル作成時から0600・ACL無継承を確認します。
- 任意のAntigravity連携は、同じユーザーが起動した正規Google署名のAntigravityアプリのローカルAPIを読みます。接続用トークンはメモリ内だけで扱い、接続確立後に正規プロセスの受理済みTCPソケットと照合できた同じIPv4 loopback接続にだけ送信します。確認できない場合は送信しません。AIMeterによる新規ログイン・資格情報の保存・Antigravityの自動起動は行いません。
- これらの連携先APIへの要求に、ローカルログ内のコードやプロンプト本文を含めません。OpenAI / GCPの外部APIは上記の固定HTTPSホストへ接続し、リダイレクトを拒否します。応答は1件8MiB・1回の更新合計32MiB、全体60秒を上限に読み込みます。
- 大きすぎるファイル・行、過剰な探索件数、不正な数値は拒否します。入力制限に達した収集では以前の集計ファイルを保持します。ログのルートにsymlinkを指定した場合は拒否するため、実体のパスを指定してください。時間制限は協調的な検査であり、OSのI/Oタイムアウトではありません。

個人ログ、集計ファイル、APIキーをIssueやPull Requestに添付しないでください。
