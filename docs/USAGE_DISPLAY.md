# 残量と使用量の表示

通常のカード、メニューバー、macOSのWidgetは、サービス名、期間、残り割合を中心に表示します。公式値、設定上限からの目安、未取得を区別し、必要な補足は詳細から確認できます。

## 表示設定

- 一般設定の「トークン量・利用回数を表示」は初期OFFです。ONの場合は利用量と単位を追加します。「要点表示／全枠表示」とは独立しています。
- 公式残量には取得した値を使い、設定上限からの残量には「約」を付けます。公式値が必要なサービスの未取得状態から、架空の割合を作りません。
- 未取得、更新失敗、数値エラーを区別します。不正な値を残り0%のバーへ置き換えません。
- 各サービスの情報ボタンから、データ元・プランの補足、API換算額（参考）、有効枠のリセット日時を確認できます。換算額は通常カードとWidgetには表示しません。
- Codexの `rate_limits.plan_type` などの識別子を、契約上のプラン名称とは断定しません。
- 数値が非表示の場合、アクセシビリティの読み上げからも使用量を除きます。使用量が表示される場合は、量・上限・単位の役割を伝えます。

## Widgetへの反映

表示設定を本体からWidgetへ共有します。schema 4では、数値表示OFFなら使用量・上限・その表示文字列を保存しません。費用は保存しません。割合・更新時刻・期限などは表示のために残ります。本体の集計データは別に保持します。

旧snapshotで表示設定が欠けている場合はOFFとして読みます。共有ファイルの更新を確認できない切替は未適用として案内します。詳細は [PRIVACY.md](PRIVACY.md) と [WIDGET_LAYOUT.md](WIDGET_LAYOUT.md) を参照してください。

## 検証

同じ合成データで数値表示OFF/ON、要点/全枠、設定保存と再読込、トークン以外の単位、不正値、未取得、更新失敗、旧snapshotの移行を確認します。読み上げ文字列も表示設定と合わせて検証します。

画面上の情報配置、実際のVoiceOver音声、WidgetKitの実表示、各対応OSでの操作と利用者の理解は、自動テストとは別の確認項目です。
