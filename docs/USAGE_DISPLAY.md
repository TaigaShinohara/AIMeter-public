# 利用量と残量の表示

AIMeterは、サービスごとの残り割合を中心に表示します。表示値には、サービスから取得した
公式値、利用者が設定した上限に対する目安、未取得の状態があります。
それぞれを区別し、公式の請求額や利用可能量と同一の値として扱わないでください。

## 通常表示と詳細

- 通常のカードにはサービス名、期間、残り割合とバーを表示します。残量が未取得の場合は
  割合やバーを表示しません。
- 一般設定の「トークン量・利用回数を表示」は初期状態でOFFです。ONにすると、
  取得できた利用量と単位を追加表示します。設定上限から計算した残量には「約」を付けます。
- 「要点／全枠」の切替は、利用量の表示設定とは独立しています。有効な期間枠を設定してから、
  要点だけを表示するか全枠を表示するか選べます。
- 各サービスの情報ボタンでは、「データ元・プランの補足」、参考のAPI換算額、
  有効な期間枠のリセット日時を確認できます。
- `prolite`などのログ内のプラン識別子は、契約上の正式名称を保証するものではありません。
  補足にはAPI、ローカルログ、GCP、任意のメモなどの情報も含まれます。

## 値の状態

| 状態 | 表示・扱い |
| --- | --- |
| 公式残量 | 取得した割合を表示します。公式値の0%は0%として扱います。 |
| 設定上限からの目安 | 「約」を付けた割合として表示します。 |
| 未取得 | 割合、残量バー、逼迫順位、残量警告に含めません。利用量の表示がONなら、取得できた推定使用量を表示します。 |
| 数値エラー | 「—」とエラー表示を使い、残り0%のバーとして表示しません。 |
| 更新失敗 | 更新失敗の状態を表示します。残量の未取得とは別の状態です。 |

読み上げ用の説明も利用量の表示設定に従います。利用量がOFFなら数量を含めず、
無効な値は数値エラーとして説明します。

## macOSのWidget

Widgetは本体が保存した表示情報と表示設定を読みます。独自にローカルログやAPIを集計しません。
表示設定を含まない旧スナップショットでは、利用量の表示をOFFとして読み込みます。
Geminiの旧スナップショットから、設定上限に基づく割合を公式残量として引き継ぐことはありません。

データ未取得・読込失敗・全サービス無効の状態と、ギャラリープレビューのサンプル表示は
別々に扱います。実際の反映時刻はmacOSが調整します。

## 検証の範囲

合成データで、利用量OFF／ON、要点／全枠、非トークン単位、無効値、未取得、更新失敗、
設定保存、旧Widgetスナップショットの読込を検証できる構成です。

コードや描画のテストだけでは、新規ユーザー環境の初回起動、OSのWidgetKitによる実表示、
VoiceOverの音声、IntelやmacOS 14での実行、利用者の理解しやすさまでは確認できません。
配布時は実際に確認した範囲と未確認の環境をリリースノートに記載してください。
