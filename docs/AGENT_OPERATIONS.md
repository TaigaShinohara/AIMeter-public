# AIMeter 操作カタログ

AIMeter の全操作の棚卸し（agent_friendly_app_design スキルの正本様式）。利用者が画面で名前を言える操作を粒度とし、内部の小処理は載せない。
カタログに無い操作を CLI へ場当たりで足さない。先にこのカタログへ登録し、狙いを添えてから実装する。
現状監査と到達レベルは [AGENT_AUDIT.md](AGENT_AUDIT.md) を参照。機械の経路は、読み取り系 CLI（`AIMeterCLI`）を実装した操作については「実装済み」と記し、それ以外は「案」（未実装）のまま残す。CLI の使い方は [AGENT_GUIDE.md](AGENT_GUIDE.md) が正本。

凡例: 破壊的 = 取り消しができない、またはデータ・資格情報を失う操作。種別 B = 画面まで案内でき、最後の 1 操作だけ人間が行うもの。

## アプリ外の人間専用手続き（参考）

アプリの画面操作ではないが、AIMeter の運用に付随し、機械化しないと宣言するもの。

| 手続き | 理由 |
|---|---|
| Mac App Store への提出と審査対応 | 提出確定は本人の承認ゲートであり、自動化しない |
| 規約への同意（Apple Developer 等） | 契約行為であり本人の確認が必須 |
| 支払いの確定（開発者プログラム年会費等） | 金銭の確定操作であり本人の確認が必須 |
| 署名・公証・配布 Release の公開 | 配布の境界操作であり、docs/RELEASING.md に従って別作業として扱う |
| 実機での見え方の判定 | 身体感覚の判定（画面の見え方）であり、スクリーンショットや数値で代替しない |

## 棚卸しの補足

- 「履歴の確認」は現行の GUI に存在しない操作のため、独立した操作としてはカタログに入れていない。CLI の `history` コマンドは「最終更新の状態を見る」の一部として、残っている記録（最終更新時刻と更新失敗フラグ）のみを返し、永続履歴が無いことを正直に明示する。履歴を機械向けに返すには、実行履歴の永続化が別途必要。
- ヘルプの閲覧は画面を開く行為のみで状態を変えないため、独立した操作としては数えていない。
- 人間専用の内訳: 主要操作 32 件中 8 件（API キーの保存・削除・移行、フォルダ選択、アプリ更新の実行、初回セットアップ、macOS ウィジェットの追加/削除、アプリの終了）。このほかアプリ外の手続き 5 件を人間専用と宣言する。
