# 上部のひとこと案内

本体とメニューバーの上部には、最も気になる残量を一つの短い案内として表示します。透明な球体と二つの目で表したLiquidBall（略称「リボ」）を添え、詳細は既存のサービス一覧で確認できます。

## 情報の選び方

入力は有効なサービスと期間の `PeriodUsageMetric` です。メニューバーのタイトル表示設定からは独立しています。残量比率の昇順で選び、同率はサービスIDと期間順で固定します。

- 表示サービスなし：設定からサービスを有効にする案内。
- 未取得：初回更新中・未取得・更新失敗を区別し、架空の残量を表示しません。
- 取得済み：15%未満は「残りわずか」、35%未満は「少なくなってきたよ」。最少残量のサービス名、期間、残量を表示します。
- 設定上限からの残量は「設定上限の目安」と明示します。0%をサービスの利用不能と断定せず、公式残量が未取得のサービスを0%へ変換しません。
- 更新中も取得済みの低残量を保持し、前回値・更新中と明示します。失敗、5分以上の経過、時刻不明・未来、リセット経過は鮮度の問題として案内します。経過時間は表示中も再評価します。
- 低残量がない場合は、取得失敗・鮮度不足、未知の残量、確認できた範囲の案内の順に扱います。未知の値を全体の安全性の根拠にはしません。

不正値は残量比較から除き、確認が必要な状態として残します。通信や外部生成APIで案内文を作る機能はありません。

## 表示と動き

348pt幅の内容領域で、キャラクターの隣に状態ラベル、案内文、必要な根拠・鮮度注記を配置します。長いサービス名でも本文は折り返します。警告色はラベルと細い輪郭に絞り、本文の位置と数値は動かしません。

リボは球体と二つの目だけで構成します。約4.8秒周期・上下±2ptの浮遊、約5.6秒ごとの短いまばたき、浮遊に伴う小さな伸縮を使います。影の位置は固定し、大きさと濃さを少し変えます。ウィンドウが非表示・最小化・遮蔽・閉鎖された場合は動きを止めます。

macOS 26以降では球体の内部にネイティブLiquid Glassの `clear` を使い、目や本文をガラスの効果から分離します。macOS 14/15は互換表示です。OSの透明度低減・高コントラストに対応し、視差効果低減が有効な場合は静止させます。キャラクター単体は読み上げ対象から外し、案内全体を一つのアクセシビリティ要素として伝えます。

## 検証

合成テストでは、境界値、同率、無効サービス・期間、公式値・目安・未取得、初回更新、更新中、失敗、古い値、リセット経過を扱います。描画・動作テストでは、長文、明暗、高コントラスト、透明度低減、動きの範囲、閉眼からの復帰、非表示時の停止と再開を確認します。

合成描画とwindow flagのテストは、実ウィンドウやOS設定を切り替えた確認の代わりにはなりません。実際のVoiceOver音声、利用者の読みやすさ・動きの好み、各対応OSの描画は別に確認してください。
