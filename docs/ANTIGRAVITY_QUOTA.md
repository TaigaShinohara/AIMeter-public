# Antigravityの公式残量

設定 → サービス連携 → Antigravityで有効にすると、起動・ログイン済みのAntigravityが
返す残り割合を表示する。Geminiのログ由来の推定使用トークン数は別カードに保持する。
APIキー、新規OAuthログイン、資格情報のディスク保存は追加しない。

## 取得と表示

- 同じmacOSユーザーの `/Applications/Antigravity.app` にあるlanguage_serverを検出する。
  kernelの実行パス、Google署名、アプリ識別子、UID・開始時刻とIPv4のlistenポートを検証する。
- 内部ローカルAPI `RetrieveUserQuotaSummary` を優先し、対応していない場合は
  `GetUserStatus` の測定済み残量へフォールバックする。CLIやIDE版は対象外。
- 全モデル群・枠の識別子と表示名を保持する。週次・5時間枠は明示された期間だけを使う。
  旧形式などで期間が不明ならモデル名を表示し、期間を推測しない。
- 未取得、無効枠、残量割合がないクレジット残高を0%へ変換しない。
  実測の0%は枯渇、100%は未消費として表示する。
- 残量割合から架空のトークン上限や残りトークン数を作らない。
  カードの要点表示でも全枠を確認でき、詳細にリセット日時と説明を表示する。
  メニューバーの期間指定時は同じ期間の枠のうち最少残量を使い、該当枠なしは未取得。
- 本体・メニューバー・キャラクター・Widgetは同じ残量データを使う。
  Widgetのコンパクト表示は最少残量のモデル群と期間を表示する。

## 失敗と鮮度

連携は初期OFF。有効にして更新すると取得を試みる。Antigravityの起動・ログインは本人が
行い、AIMeterはアプリを起動したり会話を実行したりしない。
失敗時は前回の公式残量をクリアし、カードに安全な固定の案内文を出す。
取得から120秒以上古い値とリセット予定を過ぎた値は未取得にする。
Widgetの保存形式はschema 4で、旧schema 1/2/3のデータは移行して読む。
Widgetは期限のtimeline entryも用意するが、OSによる実際の描画時刻は保証されない。

## 接続の制約

接続トークンはプロセス引数から必要な値だけをメモリへ読み、ログ・設定・集計ファイル・
Widgetへ保存しない。IPv4だけを接続候補とし、IPv6だけの待受やアドレス族が不明な
ポートをIPv4接続の認可に使わない。

HTTPヘッダーを渡す前にTCP/TLS接続を確立し、その接続の実際の両アドレス・ポートを、
正規PIDが保持する受理済みESTABLISHEDソケットの逆向き情報と照合する。
プロセスの署名・UID・開始時刻も再確認し、同じ接続へ一度だけ送信する。
接続や所有者を確認できない場合はトークンを送らず未取得とする。
自己署名TLSはこの接続後検証と組み合わせて扱い、再接続・別ソケットへの再送はしない。
HTTPのextension接続にも同じ検証を適用する。

数値loopbackとloopback interfaceを指定し、接続後にも両端を検査する。
HTTP redirect、Cookie、credential storage、cache、名前解決先への資格情報送信を行わない。
応答本文は1MiB、HTTPヘッダーは16KiB、wire全体にも上限がある。
Content-Length/chunked/接続終了による本文を上限付きで読み、不正な長さ・圧縮・redirectを拒否する。
候補・サブプロセス・リクエスト・全体の試行時間にも上限を設ける。
外部Google APIや資格情報ファイルへフォールバックしない。

内部APIはGoogleによる公開互換保証がない。アプリ更新、別の設置場所、IDE/CLI版、
アカウント未ログインなどで取得できない場合は未取得になる。

## 検証

合成データのテストで、現行・旧形式、欠損、0/100%、複数モデル群、期間不明、無効枠、
不正数値・日時、入力上限、ラベル整形、設定保存、失敗後のクリア、表示の分離、
メニューバーの期間選択、Widgetの移行・期限切れ・順位再計算を確認する。

実機取得のテストは本人のログイン済みAntigravityを読むため、通常テストではスキップする。
明示的に確認する場合だけ、次を実行する。応答本文・アカウント・使用量の値は出力しない。

```sh
AIMETER_VERIFY_ANTIGRAVITY=1 swift test -j 2 --filter AntigravityIntegrationTests/testOptInLiveReadOnlyQuotaFetch
```

検証結果にはOS・アプリ版・確認項目と未確認範囲だけを記録し、個人の使用量・画面・認証情報をリポジトリへ保存しない。通常の自動テストは、実際のログイン状態、Antigravityの各バージョン、WidgetKitの実表示、Intelや最低対応OSの動作を保証しない。署名・公証・公開リリースも別の工程として扱う。
