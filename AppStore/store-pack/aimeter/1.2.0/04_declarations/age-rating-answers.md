# 年齢レーティング質問への回答素材（App Store Connect）

※ すべて実態（ユーティリティアプリ、UGCなし、課金なし）と一致。想定レーティング：**4+**

- 漫画またはファンタジーの暴力：なし
- リアルな暴力：なし
- 性的表現またはヌード：なし
- 冒涜的表現または下品なユーモア：なし
- 恐怖またはホラーのテーマ：なし
- 飲酒、喫煙、またはドラッグの使用／言及：なし
- 成人向け／きわどいテーマ：なし
- 模擬ギャンブル：なし
- 賭博およびコンテスト：なし
- 無制限のWebアクセス（組み込みブラウザ）：なし
- ユーザー生成コンテンツ（UGC）：なし
- 医療・治療情報：なし

## 輸出コンプライアンス（参考）
- 標準的な macOS の HTTPS / TLS（`URLSession` による `api.openai.com` 通信）および macOS Keychain の標準暗号化のみを使用。独自の暗号アルゴリズム実装なし。
- App Store Connect の質問では「標準の暗号化（HTTPS等）のみ使用 / 免除対象」に該当するかを開発者・ユーザー本人が最終確認して回答する。
