# 審査用メモ（App Store Connect / App Review Information 下書き）

※ 実際の審査提出前に、実ビルドでの画面・文言と相違ないことを開発者が確認すること。

## 1. サインインについて
- このアプリはログインやユーザー登録を必要としません。デモアカウントは不要です。

## 2. 基本的な動作確認手順（実ログがない審査環境向け）
1. アプリを起動すると初回の説明画面が表示され、集計するサービスを選択できます。
2. 選択したサービスごとに、macOS の標準ファイル選択パネルから読み取り対象のフォルダ／ファイルを選択します（キャンセルまたは「後で設定」を選んで後から「設定 → サービス連携」で設定することも可能です）。
3. テスト用のローカルログフォルダがない場合は、画面上の空状態・未選択状態の表示および設定画面（表示形式の切り替え、制限と予算の設定、浮遊ウィンドウの表示/非表示、最前面固定）をご確認いただけます。
4. メニューバーアイコンからメインポップオーバー、浮遊ウィンドウ、設定画面へアクセスできます。macOS のウィジェット編集画面から「AI Meter」ウィジェット（小・中・大）を追加できます。

## 3. 権限と通信に関する補足
- 本アプリは App Sandbox 内で動作し、`com.apple.security.files.user-selected.read-only` および `com.apple.security.files.bookmarks.app-scope` を用いて、ユーザーが明示的に選択したローカルログフォルダのみを読み取ります。
- ネットワーク通信（`com.apple.security.network.client`）は、ユーザーが「設定 → サービス連携」から任意で OpenAI Admin Key を登録し連携を有効化した場合に限り、`api.openai.com` へ利用量照会を行うために使用します。
- 会話本文やプロンプトを外部サーバーへ送信することはありません。
